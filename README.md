# E-Commerce Sales and Customer Intelligence Using Python

## Project Overview

This project analyzes e-commerce retail data using Python to understand sales performance, customer behavior, product performance, and profitability.

The project applies data analysis and visualization techniques to convert raw retail data into meaningful business insights.

## Objectives

- Analyze e-commerce sales and profit data.
- Understand customer purchasing behavior.
- Identify high-performing products and categories.
- Analyze regional sales and profitability.
- Visualize important business trends using Python.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab / Jupyter Notebook

## Dataset

The project uses the Sample Superstore retail dataset containing information about orders, customers, products, sales, discounts, and profits.

Important attributes include:

- Order ID
- Order Date
- Customer Name
- Category
- Sub-Category
- Sales
- Quantity
- Discount
- Profit
- Region

## Project Analysis

### Sales Analysis

Analysis of sales performance across different categories, products, and regions.

### Customer Analysis

Analysis of customer purchasing patterns and identification of important customers.

### Product Analysis

Identification of high-performing and low-performing products and categories.

### Profitability Analysis

Analysis of profit, discounts, and factors affecting business profitability.

### Data Visualization

Visualizations are created using Matplotlib and Seaborn to represent important patterns and trends.

## How to Run

1. Open the `ecommerce-analyis-jupyter.ipynb` notebook.
2. Open it using Google Colab or Jupyter Notebook.
3. Upload the `Sample - Superstore.csv` dataset when required.
4. Run the notebook cells sequentially.
5. View the generated analysis and visualizations.
